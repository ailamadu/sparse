Pre-requisites
Required before running
  • Exadata with SPARSE ASM disk group configured
  • Test Master DB in read-only or standby (not in recovery)
  • ORACLE_HOME, GRID_HOME environment variables set
  • Run as oracle OS user with SYSDBA privileges
  • asmcmd available, grid user accessible via sudo/ssh
